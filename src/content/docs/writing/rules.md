Sigma の原稿を書くときのルール集です。
ルールは次の3分類で書かれています。

- **Must** — 全員が守る。PR のチェックと校正の対象
- **Should** — レビューのときに見る。事情がある場合は理由を添えて外れてよい
- **Tips** — できると原稿が良くなる知識

出典は Qiita 記事「[LaTeXにおける正しい論文の書き方](https://qiita.com/birdwatcher/items/5ec42b35d84d3ee2ffbb)」（birdwatcher）を、Sigma 用に読み替えたものです。
読み替えの要点は、文献処理は bibtex ではなく **biber** を使うことと、図の並置には `subfig` ではなく `subcaption` を使うことです。

:::note
ルールを変えたいときは、先にこのページを更新する PR を出してください。
このサイトが決定事項の正で、Sigma 本体のリポジトリはそれに合わせて直します。
:::

## Must: 記号とスペース

- `,` と `.` の後ろには半角スペースを1つ入れる。前には入れない
- 略称は初出で定義する
- 数式中の文字列は立体で書く: `\mathrm`、`\text`、`\operatorname` を使う
- `\max`、`\min`、`\log`、`\exp`、`\arg` などは専用コマンドで書く

## Must: 参照は直書きしない

- 式は `\label` と `\eqref`、図と表は `\label` と `\ref`、文献は `\cite` を使う
- 「式(3)より」のように番号を文章へ直書きしない（並べ替えでずれるため）
- 文献は biblatex で管理し、処理は biber で行う。本文で引用していない文献は載せない

## Must: 数式環境の使い分け

| 場合 | 使うもの |
| --- | --- |
| 文中の数式 | `$...$` |
| 別行立て・番号なし | `\[...\]` |
| 別行立て・番号あり | `equation` 環境 |
| 式変形の連鎖 | `align` 環境 |
| 長い式を折り返す | `multline` 環境 |
| 式を並べるだけ | `gather` 環境 |

- `eqnarray` は使わない
- `$$...$$` は使わない（`\[...\]` を使う）

## Must: 記法の統一

- 三点リーダは、列挙には `\ldots`、演算の省略には `\cdots`
- 場合分けは `cases` 環境で書く
- 集合の縦棒は `\mid`、空集合は `\emptyset`
- 定義を表す `:=` は `\coloneqq`（mathtools）で書く
- 引用符は `` `` '' `` の形を使う
- 括弧の大きさは内容に合わせて調整する。ただし `\left` `\right` の濫用はしない

## Must: 改行と段落

- 強制改行 `\\` は原則として使わない（数式の改行は下記の基準に従う）
- 段落分けは空行で行う
- `\vspace` などで位置や余白を調整しない

## Must: 図と表

- 配置指定は `[tbp]` を使う
- 図のキャプションは図の下、表のキャプションは表の上
- キャプションは、図表だけを見て内容が分かるように詳しく書く
- 図は原則としてベクトル形式（PDF）。幅は `\linewidth` を基準に相対指定する
- `figure` 環境の中では `\centering` を使う（`center` 環境は使わない）
- 表は罫線を引きすぎない

## Must: ソースの書き方

- ソースはインデントと改行で読みやすく保つ
- パッケージの読み込みは個人のファイルで行わない（style.sty で一括管理する）

## Must: 標準パッケージ（physics / siunitx）

微分・ベクトル・量と単位は、手組みせず専用パッケージのコマンドで書きます。
読み込みは style.sty で一括して行うので、個人のファイルに `\usepackage` を書く必要はありません。

### physics — 意味のコマンドで書く

- 微分: `\dd{x}`、`\dv{f}{x}`、`\pdv{f}{x}`、高階は `\dv[2]{f}{x}`。`\frac{df}{dx}` のような手組みはしない
- 絶対値とノルム: `\abs{x}`、`\norm{\vb{v}}`（大きさは自動で合う）。`|` や `\|` の手書きはしない
- ベクトル: 太字は `\vb{v}`、矢印は `\va{v}`、単位ベクトルは `\vu{x}` で統一する
- 演算子: `\grad`、`\curl`、`\laplacian`。発散は `\div`（physics では発散の意味になる。割り算の記号ではない）
- Dirac 記法: `\ket{\psi}`、`\bra{\phi}`、`\braket{\psi}{\phi}`、`\expval{A}{\psi}`、`\mel{n}{A}{m}`。`<psi|` のような手書きはしない
- 評価バー: `\eval{f}_{0}^{1}`

### siunitx — 数値と単位はこちらで書く

- 量は `\SI{9.8}{\metre\per\second\squared}` のように書く。`9.8m/s^2` のようなベタ書きや、単位の手組みはしない
- 数値のみは `\num{12345.678}`（桁区切りや指数を自動で整形する）
- 単位のみは `\unit{\kilo\gram}`、角度は `\ang{45;30;0}`
- 不確かさ付きは `\SI{1.23(4)}{\metre}`
- 単位の綴りは siunitx の定義に従う。メートルは `\metre`（`\meter` は未定義でエラーになる）

:::caution
`\qty` は physics（括弧の自動サイズ）と siunitx（量）の両方が定義していて衝突します。
Sigma では **physics の `\qty` を残し、量は `\SI` で書く** ことを既定とします。
切り替えは style.sty で一括して行う場合だけ可能で、個人が記事ごとに変えることはしません（全体を結合したときに壊れるため）。
:::

## Must: 数式の改行基準

等式の連鎖を、1ステップごとに別行立てへ割るかどうかは、次の基準で判断します。

**次の全てを満たすなら、等式の連鎖で1行（または文中式）にする**

- 連鎖全体が版面幅に無理なく収まる
- 各ステップが、代入・公式の適用・四則演算など、説明文なしで追える自明な変換のみ
- 中間結果を後の文で参照しない（参照するなら、式番号を付けて独立した式にする）

**逆に、改行するのは次のいずれかの場合**

- ステップに理由の説明が要る
- 中間結果そのものが重要である
- 1行に収まらない

その場合も、割る位置は論理の切れ目に合わせます。

理由: `a = b = c` という連鎖は、イコールの推移性を使う数学の標準的な記法です。
一方で、別行立てと改行は、読者への「ここは非自明なので注意して追ってください」という合図として働きます。
自明な計算にその合図を使うと、読者は身構えた分だけ拍子抜けし、合図への信頼も下がります。
また、誌面の縦の面積は有限なので、自明な計算に使う分だけ、本当に見せたい式が圧迫されます。

その他の原則:

- 改行は意味の切れ目でのみ行う
- 式だけを3行以上続けない。間に理由の文章を挟む

具体例は「判断事例集」（作成中）に Before / After の組版例付きで載せます。

## Should（レビューで見る）

- 図の中の文字は大きくし、モノクロ印刷でも線種で識別できるようにする
- 半角括弧の前にはスペースを入れる（例: Mean Square Error (MSE)）
- `\bar` や `\tilde` がどこにかかっているか分かるように書く
- 複数行にまたがる数式では `split` 環境の活用を検討する
- 書いた文章は必ず読み返す。1文を長くしすぎない

## Tips

- スペースの種類を使い分ける: 改行させない `~`、狭い `\,`、中くらいの `\:` と `\;`、広い `\quad` と `\qquad`、負の間隔 `\!`
- `\ell` と `l`、`\varepsilon` と `\epsilon` の使い分け
- `#` は `\#`、音楽のシャープとは別に `\sharp` がある
- 不等号は `\le`、`\ge` の省略形も使える
- 番号を消したいときは `\nonumber` や、`*` 付きの環境を使う
- 日本語の表記は、ひらがなに開くことを意識する: できる／とき／こと／および／なお／したがって／たとえば
