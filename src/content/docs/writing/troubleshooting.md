ビルドや執筆でよく出る症状を、「症状 → 原因 → 対処」でまとめたページです。
執筆中に実際に起きたつまずきは、解決したらここへ追加してください。

## まず確認すること

対処の前に、次の2点を確認すると早く解決します。

- **今いるフォルダと、実行したコマンド**: エラーの多くは、フォルダの移動忘れや、設定ファイルの指定漏れです
- **エラーメッセージの最初の1件**: LaTeX のエラーは、最初の1件が原因で、後ろは巻き添えのことが多いです。直すのは最初のエラーから

エラーメッセージは `ファイル名.tex:行番号` の形で出ます。その行と前後を見てください。

## 参考文献が出ない・[?] になる

- **原因**: 文献処理（biber）が実行されていない、または失敗している
- **対処**:
  - コンパイルは latexmk 経由で行う（lualatex を単独で実行しても文献は処理されません）。統一設定ファイルを指定する: `latexmk -r ..\.latexmkrc 自分のファイル名.tex`
  - それでも出ない場合は、同じフォルダにある `.blg` ファイル（biber のログ）にエラーが出ていないか確認する
  - 文献ファイルの場所と、本文で読み込んでいるかも確認する

## 図が出ない・エラーになる

- **原因**: 画像ファイルのパスの書き方、拡張子の不一致が多い
- **対処**:
  - パスは `.tex` ファイルからの相対パスで書く
  - ファイル名の拡張子まで含めて、実際のファイルと一致しているか確認する
  - 画像のファイル名に日本語を使わない

## ビルドが遅い

- **原因**: ウイルス対策ソフトのリアルタイムスキャンが、中間ファイルを毎回検査していることが多い
- **対処**: Windows セキュリティの「ウイルスと脅威の防止」→「設定の管理」→「除外」で、Sigma の作業フォルダを除外に追加する

## 文字化けする・差分が全行に出る

- **原因**: 改行コードが CRLF になっている（Sigma のファイルは LF に統一）
- **対処**: VS Code の画面右下に表示される改行コードをクリックし、「LF」に変更して保存し直す

## パッケージが見つからない（File `xxx.sty` not found）

- **原因**: TeX Live がフル構成で入っていない
- **対処**: 環境構築のページどおり、TeX Live 2026 のフル構成が入っているか確認する。個別に追加するのではなく、まず編集担当に相談する（環境のばらつきをなくすため）

## 設定ファイルが効いていない気がする

- **原因**: latexmk は、カレントフォルダの設定ファイルしか自動で読みません。号フォルダ直下の統一設定は、`-r` で明示的に指定する必要があります
- **対処**: コマンドに `-r ..\.latexmkrc` が付いているか確認する。設定ファイルの個人コピーを自分のフォルダに置かない

## PDF が上書きできない・ビルドが途中で止まる

- **原因**: 開いている PDF ビューアがファイルを掴んでいて、上書きできない（Windows で起きやすい）
- **対処**: PDF を閉じてから再実行する。中間ファイルが壊れている疑いがあるときは、先に掃除してから: `latexmk -r ..\.latexmkrc -c 自分のファイル名.tex`

## 直し方が分からないとき

エラーメッセージの全文と、実行したコマンド、今いるフォルダを添えて、編集担当に相談してください。
この3点がそろっていると、原因の特定が速くなります。
