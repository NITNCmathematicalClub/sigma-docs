このサイトは、沼津高専 数理同好会の部誌『Σ』の執筆に必要な情報をまとめたドキュメントです。
初めての部員が、環境構築から最初のプルリクエスト（PR）までを迷わず進められるようにすることを目指しています。

このサイト自体が、Sigma に関する決定事項の参照元（正）です。
執筆のルールや仕様が変わるときは、先にこのサイトを更新してから、Sigma 本体のリポジトリへ反映します。

## 全体の流れ

Sigma の執筆は、次の順序で進みます。

1. **環境構築** — Git、VS Code、TeX Live 2026 を自分の PC に入れる（Windows を正とした手順を用意しています）
2. **クイックスタート** — リポジトリを clone して、サンプルをコンパイルし、1行直して PR を出すところまでを通しで体験する
3. **執筆** — 執筆ルールに沿って原稿を書く。迷ったときは判断事例集を参照する
4. **校正** — PR で校正を受け、修正する
5. **入稿** — 編集担当が全体をまとめ、入稿の手順に沿って最終確認を行う

## 最初に読むページ

まずは [執筆クイックスタート](/start/quickstart/) から始めてください。
環境構築がまだの人は、先に環境構築のページ（作成中）を済ませてから戻ってきてください。

## 困ったときは

- ビルドが通らない、図が出ないなどの症状は「つまずき対処表」（作成中）にまとめていきます
- このサイトに載っていないことは、編集担当に聞いてください。ほかの部員もつまずきそうな内容であれば、対処表や各ページへの追記を検討します
